# v1.1.1 验证记录

日期：2026-11-04。基线：`4556ea5`。本地环境：Windows、Python 3.14.7、pypinyin 0.55.0。

## 回归测试

运行 `python -B -m unittest discover -s tests -v`：27 项测试通过。

- 文本：混排顺序、完整字母读法、百分数、万位补零、小数、年份、电话号码、句点停顿、词组读音、变调和轻声。
- 韵律：固定种子可复现，7 个风格与 3 组速度/拍号组合的音符和控制点合法。
- 音高：音域统计与原扫描一致，支持共享端点、空曲线、乱序点和曲线修改；导出遵循实际 PBS。
- SVIP3：解码实际输出的 protobuf 文件，验证 MIDI 67 对应 6700 音分、多音符及非零偏移。
- 其他输出：VSQX XML 和 Job Plugin 的音符/控制点一致；USTX 内容中的毫秒与音高单位正确；OpenSVIP JSON 保留现有字段模型。
- 性能结构：各导出器每次输出仅建立一次曲线索引，不再按音符重新遍历整条曲线。

GitHub Actions 配置覆盖 Windows Python 3.10 和 3.14，CI 实际运行结果见对应提交的 Checks。

## 曲线查找性能

运行 `python tools/benchmark_generation.py`，每项执行 3 次，取中位数。输入重复 `ni3 hao3 shi4 jie4`，默认种子和参数。

为隔离曲线查找的影响，两条路径共用修正后的 SVIP3 写出器；旧路径替换为每音符扫描全曲线，新路径使用时间索引。以下不是不同版本二进制之间的端到端比较。

| 音节数 | PIT 点数 | 核心生成（秒） | 音域完整扫描（秒） | 音域索引（秒） | SVIP3 完整扫描（秒） | SVIP3 索引（秒） |
|---|---:|---:|---:|---:|---:|---:|
| 100 | 5,413 | 0.0409 | 0.0309 | 0.0011 | 0.0715 | 0.0847 |
| 500 | 27,087 | 0.1542 | 0.8351 | 0.0071 | 0.9530 | 0.1105 |
| 1,000 | 54,204 | 0.2790 | 4.3063 | 0.0228 | 3.8671 | 0.1887 |

三组音域数值和导出文件字节均一致。1,000 音节下音域统计约快 189 倍、SVIP3 写出约快 20 倍；短输入的导出包含索引开销和运行噪声，本次 100 音节没有提速。耗时受机器负载和磁盘影响，不作为 CI 硬门槛。
