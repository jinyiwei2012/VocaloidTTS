VocaloidTTS v1.1 · 快速开始
============================

1. 双击 VocaloidTTS.exe
   - 自动检测 VOCALOID4 / VOCALOID5；找不到会提示选择
   - 也可以稍后点右上角“编辑器”设置路径
2. 在左上角选择“中文文本”或“拼音输入”
   - 拼音输入：空格分隔音节，数字标声调，如 ni3 hao3 shi4 jie4
   - 轻声写 5 或 0：ma1 ma5
   - 某个音素不准时可用 ni3|n_i 覆盖
3. 在“歌姬”下拉框选择声库
   - 每次启动自动扫描注册表、VoiceDB、所有固定磁盘
   - 找不到时点“歌姬”右侧“＋ 添加文件夹”，选择声库目录
   - 添加过的目录会保存，下次启动继续扫描
   - 乐正绫 V3 会显示为“乐正绫 · V3”
4. 输入文字/拼音，或点“自然朗读 / 戏剧朗读”等预设
   - 也可以点输入框右上“导入 TXT”，或直接把 .txt 拖进窗口
   - 输入和调参数时不会实时预览，也不会生成工程
5. 调声调滑条：
   - 一声 G3，二声 F#3，三声 E3，四声 F3，轻声 E3
   - 五个声调滑条各自独立；拖动、滚轮、方向键都可调，双击复位
   - 二声先压低再升高，四声先升高再降低
   - 想更有起伏：起伏 1.55–1.80，力度 1.45–1.70，语速 0.92–0.98
6. 设置 BPM 和拍号：
   - 默认 120 BPM、4/4
   - 可改 90/3/4、140/6/8 等，Part 会自动从第 5 小节开始
7. 点“生成工程 ▼”，选择格式：
   - VOCALOID VSQX（默认）：V4/V5 用 Ctrl+O 打开
   - X Studio 3 (.svip3)：打开后把临时歌手改选洛天依
   - OpenUTAU (.ustx)：打开后给占位轨道选择本机声库
   - OpenSVIP (.svip)：JSON 交换工程，可继续转换
8. 选择“载入”目标 V4/V5 时，可点“载入 V4/V5”自动打开
9. 按空格试听；V4/V5 可用“文件 → 导出 → 波形”导出 WAV

格式与参数说明：
- 四种格式共用同一份音符、PIT、DYN/BRE/GEN 数据
- 新增“性别”滑条：-100 更低沉，+100 更明亮，默认 0
- X Studio 3 没有公开的洛天依 UUID，导出时临时借用内置女声“陈水若”的 ID；轨道名保持“洛天依”，打开后可改选
- OpenUTAU 只写占位歌手，不绑定真实声库
- OpenSVIP 为实验性 JSON 导出

关闭与托盘：
- 点右上角“关闭”后会驻留系统托盘，不会退出
- 右键托盘图标：显示主窗口 / 退出 VocaloidTTS
- 左键双击托盘图标也会恢复窗口

注意：
- v1.0 起工具与 V4/V5 都使用 C3=60 的八度标记
- 工具里的一声 G3（MIDI 67）在 V4/V5 里也显示 G3
- 旧工程需要重新生成；旧版设置会自动 +12 半音迁移
- VSQX 是 4.0，V4/V5 都能打开；V5 可另存为 .vpr
- V4 Job Plugin 只适用于 V4；V5 直接打开 VSQX
- 自动“载入 V4/V5”失败时，手动 Ctrl+O 即可
